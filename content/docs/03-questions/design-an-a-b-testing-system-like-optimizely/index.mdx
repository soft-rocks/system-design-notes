## Overview

An A/B testing system for running experiments at scale: deterministic traffic allocation, consistent user-to-variant assignment, real-time feature variation, statistical analysis with multiple comparison correction, and experiment layering to run concurrent non-interfering experiments.

**Key design decisions:**
- **Deterministic hash-based assignment**: `hash(user_id, experiment_id) % bucket_size` ensures the same user always gets the same variant across all services and devices.
- **Real-time variant serving**: Distributed caches close to the client for &lt;10ms p99 assignment decisions.
- **Layer architecture**: Experiments are organized into layers to prevent interference between concurrent experiments.
- **Sequential testing with alpha-spending**: Proper statistical correction for continuous monitoring without inflating false positive rate.

**Scale:** 10B+ events/day, 50K+ experiments running concurrently, 100M+ users tested daily.
