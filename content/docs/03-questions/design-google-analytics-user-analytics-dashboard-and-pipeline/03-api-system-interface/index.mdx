## Event Collection API (Client-Side)

### Measurement Protocol (HTTP)

`POST https://www.google-analytics.com/collect?v=2&t=\{event_type\}&tid=\{G_ID\}&epn=\{event_name\}&ep=\{event_params\}&sid=\{session_id\}`

| Parameter | Description |
|-----------|-------------|
| `t` | Hit type: page_view, event, screen_view, conversion, ecommerce |
| `tid` | Tracking ID / G-ID |
| `uid` | Authenticated user ID |
| `sid` | Session ID |
| `dl` | Document location (URL) |
| `dt` | Document title |
| `dh` | Domain hostname |
| `dr` | Referrer |
| `ul` | User language |
| `ri` | Request ID (for dedup) |

- Event parameters: `epn=\{name\}&ep.\{param\}=\{value\}` pairs
- Payload: gzip compressed; max ~50KB per batch

### Batch Endpoint

`POST https://www.google-analytics.com/batch` — up to 20 events per request. Reduces HTTP overhead for mobile SDKs.

### Debug Endpoint

`POST https://www.google-analytics.com/debug/collect` — returns parsing results.

### Signed Protocol

HMAC-SHA256 signature for server-side measurement protocol to prevent spoofing.

## Event Collection API (Server-Side)

### Measurement Protocol API v2

`POST https://www.google-analytics.com/mp/collect?measurement_id=\{G_ID\}&api_secret=\{SECRET\}&client_id=\{CID\}&user_id=\{UID\}`

**Body:**
```json
{
  "events": [
    {
      "name": "page_view",
      "params": \{"page_location": "https://example.com", "page_title": "Home"\},
      "timestamp_micros": 1714712345000000
    }
  ]
}
```

Supports server-to-server: enhanced privacy, server-side session injection, server-side client_id generation.

### Google Tag Manager Webhook

`POST https://tags.googleapis.com/v1beta/accounts/\{ACC\}/containers/\{CON\}:publish` — pushes container config.

## Query API (Data API)

### Reports: batchGet

`POST https://analyticsdata.googleapis.com/v1beta/\{property=properties/*\}:batchGet`

**Body:**
```json
{
  "reports": [{
    "dateRanges": [\{ "startDate": "2026-04-01", "endDate": "2026-04-30" \}],
    "dimensions": [\{ "name": "country" \}, \{ "name": "pagePath" \}],
    "metrics": [\{ "name": "activeUsers" \}, \{ "name": "screenPageViews" \}],
    "dimensionFilter": \{ "filter": { "fieldName": "country", "stringFilter": { "value": "US" \} } },
    "orderBys": [\{ "dimension": { "dimensionName": "activeUsers" \}, "desc": true }],
    "limit": 100,
    "samplingThresholdSize": 100000
  }]
}
```

**Response:**
```json
{
  "reports": [{
    "dimensionHeaders": [\{ "name": "country" \}, \{ "name": "pagePath" \}],
    "metricHeaders": [\{ "name": "activeUsers", "type": "TYPE_INTEGER" \}],
    "rows": [{
      "dimensionValues": [\{ "value": "US" \}, \{ "value": "/home" \}],
      "metricValues": [\{ "value": "1234" \}]
    }],
    "totalRowCount": 50,
    "metadata": {
      "samplingSpaceSizes": \{ "shortRunSize": 1000000, "longRunSize": 5000000 \}
    }
  }]
}
```

## BigQuery Export API

### Raw Event Data Export

- Daily table partitioning: `events_*` tables partitioned by `_PARTITIONTIME`
- Schema: nested repeated fields matching GA4 event model
- Export schedule: 2-4 hours after UTC midnight for previous day
- Query: `SELECT * FROM \`project.dataset.events_\` WHERE _PARTITIONTIME BETWEEN '2026-04-01' AND '2026-04-30'`

### Export API

| Endpoint | Description |
|----------|-------------|
| `POST /bigquery/v2/projects/\{project\}/queries` | Run ad-hoc queries |
| `projects/\{project\}/exports/\{export_id\}` | Scheduled export to GCS |
