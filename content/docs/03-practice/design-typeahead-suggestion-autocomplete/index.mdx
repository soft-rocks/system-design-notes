## Overview

A typeahead (autocomplete) service returns ranked term suggestions as a user types, matching input prefixes against a massive dictionary of billions of terms. It must support typo tolerance, personalization, trending detection, and multi-language queries while maintaining sub-50ms p99 latency at 10M+ QPS.

Key design challenges:
- **Latency**: Sub-50ms p99 end-to-end from a dictionary of 100B+ terms
- **Scale**: 10M+ QPS with 10B+ distinct prefix entries
- **Quality**: Relevance scoring that balances global popularity, user personalization, and recency
- **Resilience**: Graceful degradation when parts of the system fail
