## Overview

A hotel booking system for 50,000 partner hotels (5M rooms) serving 100M monthly active users. The system handles room availability management, reservation booking across multiple channels (direct website, OTA partners, GDS), dynamic pricing, and guest loyalty integration.

**Key design decisions:**
- **Active-Active reads, Active-Passive writes**: Search is globally distributed; bookings use a single PostgreSQL master for inventory consistency.
- **Room-type-level availability**: Atomic unit of availability is the room type count, not individual rooms — reduces write contention 5x.
- **Blockhold pattern**: 15-minute atomic inventory reservation during checkout to prevent double-booking.
- **CDC-based data distribution**: Debezium captures PostgreSQL changes for downstream consumers (ES index, loyalty, notifications).

**Scale:** 5M rooms, 50K peak searches/sec, 5K peak bookings/sec, 99.99% availability target.
